# T031　多出来的那一停：被迫还是主动

由 `analysis/extra_stop/run_extra_stop.py` 离线生成；只做描述统计，不评价策略、也不写建模建议。阈值在脚本里事先固定（见下）；两次运行输出一致。

## 口径与事先固定的阈值

- 主样本：T028 里“绿旗下多停一次”的车对；对照组：T028 里“SC/VSC 下多停一次”的车对。
- **轮胎衰减更快**：T026 第一段斜率差（多停 − 少停）≥ **0.03 s/圈**；或进站前 5 圈相对该段前 5 圈的上升量差 ≥ **0.60 秒**。
- **停车异常**：多出那次进站的 lane/pit duration > 该赛道中位数 + **3.0 秒**。
- **被堵 / 战术**：进站前 3 圈中任一圈距前车 < **1.0 秒**；或同队/前后名次对手在本次进站前 0–2 圈内进站（跟进/回应），或前车在本次进站后 0–2 圈内进站（undercut 尝试）。
- **分组优先级**：轮胎衰减更快 → 停车异常 → 被堵 / 战术 → 无明显原因（主动）；一个车对可能同时满足多个，只按优先级归入一组，前 4 条的标志仍各自统计。
- 用时差 = T028 的“多停方 − 少停方”累计用时差（正 = 多停更慢）。

## 观察到的现象

1. **被迫组只占约三成：** 主样本 82 对里，轮胎衰减更快 17 对、停车异常 6 对，合计被迫 **23 对（28%）**；被堵/战术 **34 对**；无明显原因（主动）**25 对**。
2. **各组的用时差都为正（多停更慢）；停车异常组最慢，主动组也不快。** 被堵 / 战术：n=34、均值 +12.1 秒；无明显原因（主动）：n=25、均值 +19.5 秒；轮胎衰减更快（被迫）：n=17、均值 +14.9 秒；停车异常（被迫）：n=6、均值 +32.8 秒。
3. **对照（SC/VSC 下多停）整体更快**：均值 -11.6 秒（n=26）；主样本均值 +16.4 秒。这与 T028 一致：SC 下多出的那一次进站更像“免费进站”，与绿旗下多停的性质不同。
4. **轮胎/交通指标并不完全重合：** 第一段斜率差为正（多停方衰减更快）的比例 32%（44 对可用）；进站前被堵占比 34%；任意战术信号占比 32%。

## 这些数据不能说明什么

1. **T026 第一段斜率覆盖率有限**：只有第一段 ≥10 个干净圈的 stint 才有斜率，主样本 82 对里只有 44 对；其余靠上升量或其它标志判断，轮胎状态的分类并不完整。
2. **“被迫”是代理，不是直接观测。** 轮胎衰减差、停车异常、被堵、战术都只是代理；车损、前翼更换、引擎模式、队内指令等无法从这些数据里直接看到。
3. **阈值是事先固定的经验值，不是估计出来的最优切点。** 换阈值会改变分组人数（例如斜率差 0.03→0.05），所以分组结果应看作“按预先定义的规则做的描述”，不是唯一解。
4. **停车时长用 lane/pit duration 代理车损。** OpenF1 `stop_duration` 半数缺失，这里优先用 `lane_duration`、否则 `pit_duration`；它包含进站通道时间，长停车不一定等于车损。
5. **交通与位置用累计时间/名次重算。** 与官方名次有已知差异（T023）；“出站后 ±2 秒车数”只算同圈完成的车，被套圈车/进出站中的车可能被漏掉。
6. **战术窗口是粗窗口。** 只检查同队和前后各一名车手在 0–2 圈内的进站；更远的车、车队整体计划、轮胎状态变化都没有纳入。
7. **样本小、选择偏差仍在。** 主样本只有 82 对，分组后每组十几到几十对；“被迫 vs 主动”组间比较仍是观察性的，不能当因果。
8. **本单只做描述，不能直接当模拟器参数**，也不回答“车队该不该少停”（不给建模建议）。
