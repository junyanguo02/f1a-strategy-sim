# T032　“绿旗多停一次更慢”的稳健性检验

由 `analysis/extra_stop_robustness/run_extra_stop_robustness.py` 离线生成；只做描述与检验，不建模、不评价策略。随机过程只有按比赛整群自助（2000 次）与置换检验（2000 次），种子固定 SEED=20261117；两次运行输出一致。

## 口径

- 样本：T028 的“进站次数差 1”车对（主样本 = 绿旗下多停，对照 = SC/VSC 下多停）；同停车对（差 0）作为调整回归的基准组。
- 主结果变量：用时差 = 多停方 − 少停方累计用时（正 = 多停更慢）；另一种结果变量：完赛名次差 = 多停方 − 少停方的名次（正 = 多停方名次更靠后）。
- **整群自助**：按比赛（`race_key`）有放回抽整组车对，2000 次，取均值 2.5/97.5 分位。
- **置换检验**：在每个比赛内把每对车的“多停/少停”方向随机翻转（保持车对结构），2000 次；p = (1 + #{置换均值 ≥ 实际均值}) / (1 + 2000)（单侧：多停更慢）。
- **调整回归**：`time_diff ~ 截距 + 多停指示 + 发车位差 + 第一段配速差`，不同进站次数组 + 同停车对合并，标准误按比赛聚类；“排除被迫后”只保留 T031 分组里不属于“轮胎衰减更快”“停车异常”的绿旗车对。
- **剔除极端值**：在绿旗主样本里去掉 |用时差| 最大的 5%（按 95% 分位切）。
- **分样本**：赛季、车队档次（该季 Jolpica 车队积分前 5 / 后 5）、赛道类型（街道 / 常规）。

## 观察到的现象

1. **主效应方向稳定、区间不含 0：** 绿旗多停均值 +16.43 秒，整群自助 95% 区间 [+8.77, +25.02]（n=82）；SC/VSC 组 -11.61 秒，区间 [-28.37, +3.29]（n=26）。
2. **排除被迫多停后仍为正：** 绿旗剩 59 对，均值 +15.20 秒；调整回归里多停系数 +10.33 秒（按比赛聚类 SE 3.62，n=426）。
3. **置换检验：** 实际均值 +16.43 秒，置换零分布均值 +0.01（SD 5.32），单侧 p = <0.001。
4. **名次差方向一致：** 绿旗名次差均值 +2.26 位，区间 [+1.15, +3.34]（n=74）；SC 组 +0.56 位；排除被迫后的名次差回归系数 +1.33（SE 0.43）。
5. **剔除极端 5% 后仍为正：** 去掉 4 对（|用时差| > 66.7 秒），剩 78 对，均值 +13.96 秒，区间 [+7.84, +20.56]。
6. **分样本方向一致：** 赛季 2023：+8.0 秒（n=16）；赛季 2024：+25.0 秒（n=29）；赛季 2025：+12.9 秒（n=20）；赛季 2026：+14.0 秒（n=17）；车队档次 前 5：+12.6 秒（n=34）；车队档次 后 5：+19.2 秒（n=48）；赛道类型 街道赛：+21.7 秒（n=18）；赛道类型 常规赛道：+14.9 秒（n=64）。

## 这些数据不能说明什么

1. **仍然是观察性比较。** 同队两车不是随机分配进站次数；多停方可能本来就更慢/被交通困住/执行车队计划，所以“多停更慢”是关联，不是因果。
2. **样本小、分组后更小。** 绿旗主样本 82 对，排除被迫后 59 对；分样本（赛季/车队档次/街道）每组只有几到几十对，均值不稳定。
3. **整群自助只重抽比赛，不重抽“车对选择”。** 区间反映“换一批比赛”的抽样波动，不覆盖策略选择偏差；置换检验只检验“方向是否偏离随机”，也不能消除选择偏差。
4. **名次差受罚时/DSQ/套圈影响。** 名次来自 Jolpica 完赛名次；用时差对套圈/未完赛车对按较短一方对齐，仍有 1 圈内的误差。
5. **排除被迫依赖 T031 的代理与事先阈值。** 换阈值（斜率差 0.03→0.05 等）会改变“被迫”集合，从而改变排除后的均值；本单沿用 T031 的既定阈值，不做调参。
6. **车队档次按 Jolpica 车队积分分档。** 前 5 / 后 5 是赛季末积分排名，不是赛中实力；2026 有 11 支车队，中间 1 支（以及未知映射）不进入前 5/后 5 分样本。
7. **剔除极端值只去掉了 |用时差| 最大的 5%**（4–5 对），对尾部很敏感；换成 10% 或按名次差剔除会得到不同数字。
8. **本单只做描述与检验，不能直接当模拟器参数**，也不回答“车队该不该少停”。
