# 轮胎衰减模型 v3.1

按赛季拟合 NumPyro 分层模型，使用逐圈时间、胎龄、剩余圈数与前车间距。拟合入口为 fit_tyre_v3_1.py。训练命令、后验输出路径与数据构建顺序见 [复现指南](../../scripts/download_data.md)。

## 模型

1. 赛季层：各站的燃油项、衰减、配方偏移围绕所在赛季的均值，赛季均值围绕总体均值。2026 新规后衰减水平明显不同，必须分开。
2. 交通项：上一圈结束时距前车 <1 秒、1–2 秒、时间差缺失三个指示变量（来自 T012 的 gap_ahead_prev，只用本圈开始前已知的信息）。
3. stint 随机截距：对应 T010 发现的同一段轮胎内误差持续偏移。留出集的 stint 在预测时从随机截距分布里抽新值。

## 已知局限
- 交通项只区分前车距离，没有区分前车是否被套圈、是否同配方。
- stint 截距吸收的是整段的平均偏移，T010 发现的逐圈自相关（去掉 stint 均值后仍约 0.39）还没有建模；若留出集 90% 区间覆盖仍明显低于 90%，下一版加 AR(1)。
