# f1a.sim — 单车蒙特卡洛比赛模拟器（v0.1）

作者：Claude（2026-11-18）。只模拟一辆车，不含对手、超车、交通、天气变化。

## 圈时模型
绿旗圈：`基础圈时 + k0[c] + gamma·rem_c + beta[c]·(胎龄−10) + kappa[c]·(胎龄−10)² + u_stint + sigma·t(nu)`
- 参数来自 tyre v3.1 后验（`models/tyre_v3/outputs31_<赛季>/posterior_core.npz`），每次模拟随机取一个后验抽样，参数不确定性随之传入结果。
- 基础圈时 = 该站 model_laps 干净圈中位数；rem_c 用拟合时的同站剩余圈数均值中心化。
- u_stint 每段新抽一次 N(0, sd_stint)。
- SC / VSC 圈：基础圈时 × 倍数，倍数是从 laps_pit_filled 的 SC / VSC 圈估计的中位数（含部署与结束过渡圈），无噪声。

## 进站损失
- 正常：本赛道相对进站损失样本（≥10 个），否则全体（T013）。
- SC / VSC 下：按进站发生在该段第几圈取 T018 的经验样本：第 1 圈 = “宣布后 0–60 秒”+“60 秒–1 圈”，第 2 圈 = “1–2 圈”，第 3 圈起 = “2 圈以后”。

## SC / VSC
第 1 圈单独概率；之后每圈出现率按比赛进度 5 段，来自 90 场全赛道基线（fcy_episodes），持续圈数取经验分布。`RaceConfig.fcy_rate_scale()` 可整体缩放做敏感性分析。

## 公平比较
`evaluate()` / `optimize_stops()` 让所有策略共用同一组随机数（SC 时间线、噪声、stint 截距、进站损失分位），差值的区间是配对差。

## 已知局限（v0.1）
- 不含交通：进站后落入车流的代价不在内（v3.1 的交通项未接入）。
- 第 1 圈起步、轮胎预热、燃油以外的赛道演化未单独建模。
- FCY 圈内胎龄照常增加，衰减不计入圈时。
- 进站在宣布前一刻发生的情况（T018“宣布前进站”）没有单独处理。
- 出现率是全赛道共用基线，不分赛道。
