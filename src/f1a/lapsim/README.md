# 质点准稳态单圈模型

给定弧长、带符号曲率和整车参数，求闭合赛道上的飞驰圈速度与时间。来源为仓库根目录的 `external/formula-lab/work/aero-model.js`。本模块以合成赛道验证数值算法。真实赛道几何由 T048 提供，参数标定与燃油后验对照属于 T050。

## 输入和输出

```python
import numpy as np
from f1a.lapsim import CarParams, sensitivity, solve_lap

s = np.arange(0, 5000, 5.)
shape = np.exp(12 * (np.cos(4 * np.pi * s / 5000) - 1))
k = 2 * np.pi / 5000 * shape / shape.mean()   # 对称闭合椭圆形测试赛道
car = CarParams()
lap = solve_lap(s, k, car)
seconds = lap.total
dt_dm = sensitivity(car, (s, k), "mass_kg", 5.)   # 秒/kg，中心差分 ±5 kg
```

每个节点给一个曲率，单位为 1/m，左右弯符号相反。对于 N 个等距节点，最后一段按相同间距接回起点。对于非等距节点，传入 N+1 个弧长边界，末项为终点距离，曲率仍为 N 个；末段较短也用这种形式。若几何表重复列出起终点，使用全长距离数组及去掉重复终点后的曲率。函数不从曲率推算几何闭合性。返回的 `lap.v` 是 N 个节点速度（m/s），`lap.t` 是 N+1 个累计时刻（s），`lap.t[-1] == lap.total`，终点速度与起点相同。固定质量导数乘以两个单圈之间的质量变化（kg），给出对应圈时变化的一阶近似（s）；质量降低时质量差取负值。

## 参数起点与单位

数量级依据项目 `notes/lapsim_plan.md` 的初值约定，用于后续拟合。以下是整车有效参数。没有使用车队实测气动图或特定分站校准值。

| 参数 | 默认值 | 解释 |
|---|---:|---|
| mass_kg | 800 kg | 当圈整车、车手和车载燃油的总质量，燃油质量直接计入 |
| power_kW | 750 kW | 恒定的有效轮上功率；未另扣传动损失 |
| mu | 1.65 | 假设的干地有效摩擦系数 |
| cla_m2、cda_m2 | 4.5、1.0 m² | 正号表示下压力、阻力，均乘 ½ρv² 得牛顿 |
| brake_max_mps2 | 55 m/s² | 机械制动减速度上限，空气阻力另计 |
| v_max_mps | 110 m/s | 独立速度上限；传 np.inf 可关闭。无限上限且零阻力时，所有节点须有有限弯速包络 |
| front_share、static_front_share | 0.46、0.46 | 气动与静态前轴份额；静态前轴份额沿用旧模型，默认气动平衡与它匹配 |
| rho_kg_m3 | 1.20 kg/m³ | 沿用旧模型空气密度，重力加速度取 9.81 m/s² |

`aero_from_components()` 保留旧模型的演示翼面极曲线，与上述整车初值分别使用。设置示例为 `{"rear": {"angle": 18}, "front": {"installed": False}}`，角度单位为度。返回字典给出 CdA、ClA、气动前轴份额和相对所有部件在位时的质量差 `extra_mass_kg`。采用演示部件时，应以返回面积替换整车面积，质量差加到总质量，避免重复计入翼面。

## 求解与局限

1. 以 v² 为状态量，按节点限制弯速、独立最高速及功率与阻力的平衡极速。静态与气动平衡不同时，沿用旧模型对横向下压力乘较弱轴的相对支撑比例。纵向剩余抓地按摩擦圆扣除横向用量。
2. 在完整环上用 NumPy 同步迭代前向驱动及反向制动约束。旧 JS 使用原位顺序扫描与端点力；这里在段中点插值曲率并估算力，限制驱动步不得越过该段恒定曲率下的平衡速度，避免接近横向饱和时数值振荡。通过闭合段平均速度逐段积分时间。去除了旧版的 85 m/s 硬上限和 1 m²/s² 的速度平方下限；过粗步长产生非正速度、包络无界或约束不收敛时会报错。
3. 无独立限速时，直线极速由功率与气阻平衡决定。圆周解析弯速测试隔离横向约束，令阻力为零且前后轴平衡；有阻力时，维持匀速还需要纵向抓地，另有测试验证摩擦圆下的恒速解。
4. 模型忽略轮胎温度、磨损、载荷敏感性与横向载荷转移，也忽略坡度、横坡、路肩、换挡、能量回收与释放、主动空气动力学和跟车。中心线给定，不优化赛车线。参数变化会使局部约束在动力、制动和抓地之间切换，解释灵敏度前宜检查差分步长。
